4. 系统总体架构

云端服务层

SpringBoot 3.2 + Vue3 大屏 | InfluxDB时序库 + MySQL | 赛事管理/统计分析/多屏展示

边缘网关层

树莓派4B + Docker | Netty事件总线 | Redis缓存 | WebSocket推送 | MQTT协议转换

终端设备层

ESP32-S3 + 4.3"触摸屏 | Lua规则引擎 | SQLite离线存储 | MQTT上报

数据流路径

裁判终端 → MQTT → 边缘网关

边缘网关 → WebSocket → 大屏客户端

SQLite本地缓存 → 增量同步 → 云端InfluxDB

端到端延迟 ≈ 186ms (P95: 186ms)
