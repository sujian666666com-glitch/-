4.2 关键技术方案

WebSocket 实时通信

全双工长连接，浏览器大屏实时推送，P95延迟186ms，替代HTTP轮询。

MQTT + Redis Pub/Sub

嵌入式终端MQTT上报，边缘Redis本地分发，QoS保障关键事件可靠传输。

三层离线容错

终端SQLite → 边缘Redis → 云端InfluxDB，断网续传，数据不丢失。

Netty 事件驱动

主从Reactor模型，零拷贝优化，500+并发连接CPU占用<35%。

Vue3 + Pinia

响应式大屏渲染，PWA离线缓存，多终端自适应布局。

混合数据库

InfluxDB时序事件 + MySQL关系数据 + SQLite离线缓存。

技术栈：SpringBoot 3.2 · Vue 3.4 · SQLite · WebSocket · ESP32-S3 · 树莓派4B · ECharts
